# Pi Config

我的 pi 配置方案。

## 目录

- `settings.json` — 全局设置（one-dark 主题、uv python 转发等）
- `extensions/` — 已启用扩展（Ghostty 分屏、TUI 动画、pi-ask 问答）
- `extensions-optional/` — 可选扩展（auto-format）
- `prompts/` — 自定义 prompt 模板（协作准备、会议总结、日志记录、提交）
- `skills/` — 自定义技能（Neovim 插件最佳实践、人物档案归档）
- `themes/` — 自定义主题（one-dark）
- `deprecated/` — 已废弃扩展
- `APPEND_SYSTEM.md` — system prompt 追加规则
